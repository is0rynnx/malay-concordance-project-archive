About this archive

Malay Concordance

This site provides a static, searchable interface to the archived Malay Concordance Project text collection held in this GitHub repository. The original transcriptions remain unchanged. Search indexes, vocabulary lists, filters and concordance displays are generated from those source files at deployment time.

Search modes

Word
Case-insensitive token search. Multiple words require all terms to occur in the same text. Prefix a term with - to exclude texts containing it.
Phrase
Finds adjacent indexed word forms in the specified order.
Wildcard
Use * for any sequence and ? for a single character, matched against the corpus vocabulary.
Regex
JavaScript regular expression matched against vocabulary forms. Patterns are capped to protect the browser from pathological queries.
Near
Use word1 ~5 word2 or word1 NEAR/5 word2 to find forms within a word-distance window.
Word family
Heuristic Malay prefix/suffix expansion around the supplied root. Use it for discovery, not as a claim of morphological analysis.

Source fidelity

The display text is the archived MCP transcription. Editorial brackets, symbols, spelling and notes are preserved. Normalization is used only for indexing and retrieval.
