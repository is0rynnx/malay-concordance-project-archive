About

Malay Concordance makes the archived Malay Concordance Project corpus searchable in a modern browser. The collection contains historical Malay texts ranging from inscriptions and manuscripts to letters, periodicals, and printed works.

The archived transcription is always the displayed text. Search indexing normalises case and selected punctuation for retrieval; it does not rewrite the source. Each text retains the bibliographic and editorial information supplied with the archive.

Search

Word
Find a word form. Multiple words must all occur in the same text; prefix a word with - to exclude it.
Phrase
Find adjacent word forms in the specified order.
Wildcard
Use * for any sequence and ? for one character.
Regex
Match a JavaScript regular expression against indexed word forms.
Near
Use word1 ~5 word2 or word1 NEAR/5 word2.
Morphology
Expand a root through common Malay affix patterns. This is a discovery aid, not a formal morphological analysis.
