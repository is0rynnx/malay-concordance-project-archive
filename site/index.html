Search help

Search modes

Word
Find a word form. Add more words to require them in the same text. Prefix a word with - to exclude it.
Phrase
Find adjacent words in the order entered.
Wildcard
* matches any sequence of characters; ? matches one character.
Regular expression
Match a JavaScript regular expression against indexed word forms.
Proximity
Use word1 ~5 word2 or word1 NEAR/5 word2.
Morphology
Expand one root through common Malay affix patterns. Use it as a discovery search rather than a formal morphological analysis.

Results

Occurrences are grouped by source text. Open an occurrence to read it in the full transcription. Use “Matches by text” to narrow a search to one source.

About

Malay Concordance provides browser search over the texts preserved in the Malay Concordance Project archive. Bibliographic and editorial information supplied with each transcription is retained alongside the text.

The source transcriptions are displayed unchanged. Search data is generated separately for retrieval and concordance display.
